## 🌟 Executive Overview

**AUDIRA GLOW** is a bespoke, zero-dependency interactive graphics and audio framework developed by **Audira (Agus Dwi R)**. Designed as a high-performance alternative to heavy WebGL canvas textures, it calculates exact sub-pixel axonometric 3D-to-2D projection matrices directly into scalable SVG DOM trees.

### Key Highlights
- **45+ Interactive Models**: Precision isometric hardware and architectural figures.
- **6 Master Collections**: Enterprise Data Center, Cyber Lab, Audira Studio, Architectural Cities, Classic Objects, and Lumen Light Sculptures.
- **Zero External Dependencies**: Pure Vanilla ES6+, semantic HTML5, and native SVG. No heavy frameworks or large asset bundles.
- **Procedural Sound Engine**: 100% native Web Audio API audio synthesis (plasma blasts, vacuum tube harmonics, radio static, and jet turbines) with zero MP3/WAV download overhead.
- **Dynamic Luminous Glow System**: Multi-stage SVG Gaussian blur filters (`#glow`, `#soft`, `#bloom`) and a universal 6-color accent matrix with instant theme switching.
- **Living Animation Physics**: Active animation loops (`api.every` & `api.loop`) powering real-time waveforms, particle packet streams, and flywheel lerp kinematics.

## 🚀 Getting Started & Local Execution

### 1. Prerequisites
- **Git** (version 2.30+ recommended)
- **Python 3.8+** (for dev server and build automation)
- Any modern web browser (Google Chrome, Microsoft Edge, Firefox, Safari)

### 2. Clone the Repository
```bash
git clone https://github.com/Audira141415/AUDIRA-GLOW.git
cd AUDIRA-GLOW
```

### 3. Launch the Local Development Server
Run the local HTTP server on port 3000:
```bash
python -m http.server 3000
```
Open your browser and navigate to:
```text
http://localhost:3000/
```
*(This automatically opens the official **Landing Page** at `index.html`)*

### 4. Rebuild All Collections (If Modifying Source JS)
If you edit or add any scripts inside `assets/audira/`:
```bash
python rebuild_all.py
```
This automatically compiles and injects headers across all collections:
- `datacenter.html`
- `cyberlab.html`
- `audira-studio.html`
- `cities.html`
- `objects.html`
- `lumen.html`
- `computer-demo.html`
- `landing.html` -> `index.html`

### 5. Automated Git Commit & Push (`save.bat`)
To quickly save your changes, commit, and push directly to GitHub:
```cmd
save.bat
```
The script will automatically initialize Git if needed, configure the remote repository, prompt for a commit message (or use an automated timestamp), stage all files, and push to `main`.
